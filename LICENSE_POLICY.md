# License and attribution policy

This package organizes an existing research project. It does not assign a new license to the researcher's original code or manuscript. The repository owner may add their chosen code license when publishing.

Third-party code and datasets retain their upstream notices. See `third_party/` for component notices and `datasets/README.md` for the dataset source records and terms. A project-level code license, if added later, does not replace those terms.

The experimental records are copied from the original runs; formatting them into this repository does not change authorship. No paper title, author list, DOI, or publication status has been invented.
